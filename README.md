# Ement

> The third-person plural future active indicative of the Latin verb `emō` (to buy, purchase) is `ement`, which translates to "they will buy"

Modern web framework built on Custom Elements and native browser APIs.

## Development

```bash
npm install
npm run dev     # Vite dev server on :3000
npm run build   # Production build → dist/index.js
npm test        # Run all tests
```

## Usage

```javascript
import { ElElement, ElContainer, ElRouter, ElHttp, ElField } from 'ement';
```
