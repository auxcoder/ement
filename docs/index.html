Ement API Reference

Modern web framework built on Custom Elements and native browser APIs.

bootstrap

Application entry point helper. Wires together an `ElContainer`, `ElHttp`, and optionally an `ElRouter` in one call.

 computed

Lazy, cached derived values that auto-invalidate when reactive dependencies change.

 ElElement — Reactivity Design

After the template renders, ElElement finds every property name used in `{{ }}` bindings and replaces that property on the instance with a getter/setter via `Object.defineProperty`.

 reactive

Proxy-based reactivity system. Replaces AngularJS's digest cycle and dirty-checking.

 scheduler

Microtask-based update scheduler. Batches multiple reactive mutations into a single DOM update.

 ElContainer

Interface-based dependency injection container. Replaces AngularJS's `$injector` and `$provide`.

 DI Provider

DOM-based container distribution. Attaches an `ElContainer` to a DOM subtree so descendant components can resolve services without importing them directly.

 Service Tokens

Symbol constants that act as interface tokens for the DI container.

 interceptLinks

SPA link interception. Captures same-origin `` clicks and routes them through `ElRouter` instead of triggering a full page reload.

RouteOutlet

Custom element that serves as the mounting point for routed components.

 ElRouter

History-based SPA router with route groups, data resolvers, and transition hooks.

 ElHttp

`fetch`-based HTTP client with interceptors, timeout, and automatic retry. Replaces AngularJS's `$http`.

 ElField

Input binding with a `parsers → validators → onChange` pipeline, and a formatters pipeline for writing model values back to the input. Replaces AngularJS's `NgModelController`.

 ElFormGroup

Aggregates multiple `ElField` instances into a form with unified state. Replaces AngularJS's form controller (`NgFormController`).

 formatters

Model → view transform functions for use in `ElField`'s `formatters` pipeline.

 parsers

View → model transform functions for use in `ElField`'s `parsers` pipeline.

 validators

Common sync validator functions for use with `ElField`.

 animate

Web Animations API helpers for enter/leave/stagger animations. Replaces AngularJS's `ngAnimate`.

 sanitize

HTML sanitization and escaping. Replaces AngularJS's `$sce` + `$sanitize`.

 intl filters

Locale-aware display formatting using native `Intl` APIs. Replaces AngularJS's built-in `currency`, `date`, `number` filters.
